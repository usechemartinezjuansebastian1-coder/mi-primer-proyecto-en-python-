Este es mi primer repositorio en GitHub. Marca el inicio de mi camino en la programación y la automatización.

¿Qué hace este script?
Es un programa básico que interactúa con el usuario. Le pide su nombre y le devuelve un saludo personalizado en la pantalla.

Conceptos aprendidos
* Uso de la función `input()` para recibir datos del usuario.
* Uso de la función `print()` para mostrar información en pantalla.
* Concatenación de variables (unir textos).
